# Commercial Real Estate Investment Analysis

## Overview
Conducted a commercial real estate investment analysis on a 24 Hour Fitness property in the Long Beach/Orange County market using demographic analysis, market trends, vacancy data, NOI projections, ROI calculations, and IRR forecasting.
