# Intuit Dome Economic Impact Analysis

## Overview
Designed a difference-in-differences (DiD) research framework analyzing the economic impact of the Intuit Dome development on employment, income, housing affordability, and business activity in Inglewood.

## Tools & Data Sources
- ACS Data
- Zillow Data
- EDD Labor Market Data
- Excel
- Economic Research Methods

## Skills Demonstrated
- Econometrics
- Public Data Analysis
- Economic Research
- Trend Analysis
